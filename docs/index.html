UIAPduino で学ぶ マイコンC言語基礎講座 — 教材一式を公開しています

290円のマイコンとブラウザで、
C言語からアルゴリズムまで。

UIAPduino（CH32V003）は、USB でつなぐとキーボードやマウスとして動く小さなマイコンボードです。 この講座では、LED の点滅（Lチカ）から始めて、ブラウザ上の盤面でスネークを動かし、 BFS やボロノイで CPU と対戦するところまで進みます。 スライド・スケッチ・練習用 Web ページをすべて公開しているので、授業や部活動の教材としてそのまま使えます。

講座スライドを見る（PDF） WebHID Lab を開く

01この教材の特徴

1人290円、はんだ付けなし

マイコンはブレッドボードに挿すだけです。用意するのはパソコンと USB ケーブル、タクトスイッチ1個くらいです。LED はボード上のもの（Pin-2）を使います。

画面と盤面はブラウザが用意する

WebHID を使うと、ブラウザとマイコンが双方向につながります。盤面・迷路・座標はブラウザが持つので、マイコン側は「考えて答えを返す」部分だけを書けば動きます。そのぶん C言語そのものに集中できます。

不便を感じてから道具を渡す

文法を先に並べることはしません。たとえば switch 文は、Keyboard Practice 1 で「ステップを変えるたびに書き込み直す」面倒を体験してから、その解決策として導入します。

前半の話が、後半で回収される

  • 「RAM は 2048 バイト、だから型を選ぶ」
    → bool 3枚 768B を uint8_t 1枚 256B に
  • 「通信は .h に押し込む」
    → SnakeHID.h → SnakeVSHID.h
  • 「BFS 最大空間優先」
    → それが CPU Lv3。だから Lv4 に勝てない

03WebHID Lab で学ぶ C言語

講座の後半は、練習用の Web サイト UIAPduino WebHID Lab と組み合わせて進みます。 Chrome か Edge でページを開いて「デバイスを選択して接続」を押すだけで、UIAPduino とつながります。インストールは要りません。

各ページには、接続ボタン・ワークエリア・通信ログ・スケッチのソースと ZIP ダウンロード・段階的なヒントがそろっています。授業の実習ページとしても、生徒が家で続きをやるページとしても使えます。

基礎 — 通信と文法を身につける

Echo Test

16 バイトを送ると、そのまま返ってくるだけのページです。ブラウザ → マイコン、マイコン → ブラウザの両方向と、1秒ごとのカウンターを確かめます。

スケッチ：WebHIDTest ／ 第3部

HID Console

hid.Print() / hid.Println() の出力をブラウザに表示します。画面のないマイコンでも、変数の値やどこまで実行されたかが見えるようになります。

スケッチ：HidPrint ／ 第4部

Keyboard Practice

UIAPduino をキーボードとして使い、文字入力・カーソル移動・Backspace・Enter・Home を5ステップで練習します。ステップはコメントで切り替えます。

スケッチ：KeyboardPractice ／ 第5部

Keyboard Practice 2 — switch 文

同じ5ステップを switch 文で書き直します。1回書き込めば、ブラウザからステップを自由に切り替えて何度でも実行できます。

スケッチ：KeyboardSwitch ／ 第5部

アルゴリズム — 考えて、答えを返す

盤面や迷路はブラウザが管理し、UIAPduino は「次にどちらへ進むか」だけを返します。書くのはアルゴリズムの部分だけです。

Snake Solver

16×16 の盤面で、岩を避けながら決められた歩数だけ伸び続けます。レベルが上がるたびに岩が3個増えます。二次元配列で盤面を覚え、BFS で「行ける広さ」を数えて進む方向を決めます。

スケッチ：SnakeSolver ／ 第6部

Snake VS

自分のアルゴリズムが CPU と陣地を取り合う対戦スネークです。CPU 5段ラダーを3本勝負で勝ち上がります。2台の UIAPduino を直接戦わせる 2P 対戦とランキングもあります。

スケッチ：SnakeVS ／ 第7部

Rock Dodge

落ちてくる岩をよけながら得点アイテムを拾います。安全な場所にいるだけではノルマに届きません。危険を承知でどこまで稼ぎに出るか、その判断をプログラムに書きます。

スケッチ：RockDodge ／ 挑戦課題

Maze Solver

ブラウザが出す 15×15 の迷路を、UIAPduino が自分で解きます。solveMaze() に右手法 → DFS → BFS と実装を上げていきます。ゴールすると次の迷路へ進みます。

スケッチ：MazeSolver ／ 挑戦課題

図解ガイド — コードを読む前に、動きを図で見る

4つのゲームには、それぞれ図解ガイドがあります。16×16 の盤面の図の上で、配列の中身や BFS の広がり方を1段階ずつ追えます。 「図でつかんでから、コードに戻る」ための教材です。Snake Solver・Snake VS・Rock Dodge のガイドの最後には、.ino 全体を一行ずつ説明した解説も付いています。

Snake Solver 図解ガイド

スネークの「記憶」を盤面で見てみよう

2枚の bool 配列で盤面を覚える、X と Y の向き、岩の受信、countReachable() で4方向を比べるところまで。

Snake VS 図解ガイド

2匹ぶんの「記憶」と1手の決め方を見てみよう

1マスを1バイトで表す、取り合いになるマス、BFS で生き残れる広さを数える。配布スケッチを超えて勝つためのヒントもあります。

Rock Dodge 図解ガイド

落ちてくる未来を時間方向に読む

盤面を「列 X × 未来の時刻 t」に置き換え、safeAt(x, t) で生き残れる経路を探します。空間の探索を時間の探索に読み替える考え方です。

Maze Solver 図解ガイド

見えない迷路を調べながら進む

「見るだけ」と「実際に進む」の使い分け、DFS とバックトラック、BFS が波紋のように広がって最短経路を見つける様子を比べます。

講座の続きに — マウスとクラス

講座では使っていませんが、同じ流れで取り組める練習ページです。

Mouse Practice

UIAPduino をマウスとして使います。クリック、四角形の頂点クリック、ドラッグ、円を描くドラッグを、.ino に座標を書き込む形で段階的に練習します。

スケッチ：MousePractice

Mouse Practice 2

ブラウザからマウスの位置を受け取って動かす発展版です。C++ のクラスの学習にもなります。HID Console にも対応しています。

スケッチ：MousePractice2

04挑戦課題 — 授業のあとも続けられる

講座の残り時間や、持ち帰ってからの課題です。どのページもヒントが段階的に出るようになっていて、最後の段のコードだけは伏せてあります。 Snake VS と Rock Dodge にはランキング（そのパソコンのブラウザに保存）があるので、クラスの中で競い合うこともできます。

課題目標
Snake VS配布スケッチは CPU Lv3 と互角で、Lv4（ボロノイ）で止まります。ボロノイを実装して Lv4 を倒します。
Snake VS 2P2台の UIAPduino を直接対戦させます。ランキングは連勝記録です。
Rock Dodge安全な場所に乗っているだけではノルマに届きません。どこまで稼ぎに出るか、採算の判断が勝負です。
Maze SolversolveMaze() に右手法 → DFS → BFS と実装を上げていきます。

Snake VS と Rock Dodge では、スケッチの #define PLAYER_NAME に自分の名前（半角英数12文字まで）を書いて使います。2台で対戦するときは、必ずお互い違う名前にしてください。

UIAPduino は、足を上にそろえてまっすぐ縦にブレッドボードへ挿します。タクトスイッチは GND と Pin-3 につなぎます（押すと Pin-3 が LOW になります）。

パソコン

  • Windows 11 64ビット版（Intel / AMD の CPU）。ARM 版 Windows は対象外です
  • CPU は Intel N100 / Core i3 以上（おすすめは Core i5 / Ryzen 5 以上）、メモリ 8GB 以上（おすすめ 16GB）、空き容量 10GB 以上
  • Windows Update を済ませて最新の状態にしておく（HID 接続が安定します）
  • Windows のユーザーフォルダー名が半角英数字だけであること（例：C:\Users\student）
  • USB Type-A の端子（ない場合はデータ通信に対応した両端 Type-C のケーブル）

学校が管理しているパソコンを使う場合は、アプリのインストールと USB 機器の利用が制限されていないかを先に確認してください。

ソフトウェア

  1. Arduino IDE 2 をインストール
  2. 基本設定の「追加のボードマネージャの URL」に次を追加
    https://raw.githubusercontent.com/tarosay/board_manager_files/main/package_uiap_hid_index.json
  3. ボードマネージャで「UIAP」と検索し、UIAPduino HID をインストール
  4. ボードは「UIAPduino HID → HID ProMicro CH32V003」を選ぶ
  5. ブラウザは Chrome または Edge（WebHID は Firefox・Safari では動きません）

ボードパッケージとライブラリの詳細は arduino_core_ch32 を参照してください。手順は画面つきで「事前準備など」の PDF にまとめています。

07授業でつまずきやすいところ

Tools → USB の設定の切り替え

いちばん詰まりやすいところです。Snake 系（SnakeSolver / SnakeVS / RockDodge）だけが WebHID Only で、MazeSolver に移るときは Keyboard+Mouse+WebHID に戻します。WebHID を使うスケッチを WebHID なしの設定でビルドすると、次のエラーで止まるので、設定の間違いはここで気づけます。

#error "WebHID ライブラリを使うには: Tools > USB > WebHID Only
        または Keyboard+Mouse+WebHID を選択してください"

講座では、このエラーをわざと出して「エラーは読めば答えが書いてある」ことを体験する回（第5部）を設けています。

書き込みの手順

UIAPduino のボタンを押しながら USB を挿し、挿したらすぐ離す → Arduino IDE の書き込みボタン、の順です。Lチカ・キーボード・WebHID のどのスケッチでも同じ手順です。

パソコンの環境

ユーザーフォルダー名に日本語が含まれている場合は、半角英数字名のローカルユーザーを作ってから Arduino IDE をインストールします（管理者権限が必要です）。学校のパソコンでは、インストールや USB の制限も事前に確認してください。

ブラウザと接続

WebHID は Chrome と Edge だけで動きます。ページを開いたら「デバイスを選択して接続」を押し、一覧から UIAPduino を選びます。つながるのは、人が選んだ機器だけです。
